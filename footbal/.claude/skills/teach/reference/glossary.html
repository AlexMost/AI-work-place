Глосарій three.js

Терміни, які зустрічаються у 3D-гонці pool-spy (pool_spy.py → standings.html). Канонічне джерело — three.js manual.

Scene (сцена)
Корінь «графа сцени» — контейнер усього, що малюється. У коді: const scene = new THREE.Scene(). three.js: Scene — root of the scene graph.
Geometry (геометрія)
Лише форма: набір вершин. Сама по собі невидима. Напр. CapsuleGeometry (капсула — циліндр з півсферами), SphereGeometry (куля).
Material (матеріал)
Лише вигляд поверхні: колір, блиск, текстура. У гонці — MeshBasicMaterial: плаский колір, що ігнорує світло (свічення дає не світло, а bloom-постобробка).
Mesh = Geometry + Material
Видимий об'єкт = форма + вигляд, плюс позиція/поворот/масштаб у сцені. Це базова одиниця, з якої складено все: торс, голова, кінцівки, м'яч.
Group / Object3D (група)
Контейнер без власної форми. Діти позиціонуються відносно батька — рухаєш групу, рухаються всі діти разом (як колеса разом з машиною). Один футболіст — це одна Group.
Scene graph (граф сцени)
Дерево батько→дитина з груп і мешів. Трансформації успадковуються вниз по дереву.
Pivot (вісь обертання)
Прийом: кінцівку роблять дочірнім мешем у групі, зміщеним вниз, а групу ставлять на стегно/плече. Тоді поворот групи обертає кінцівку навколо суглоба, а не центру. Деталі — урок 2.
Render loop (цикл рендера)
requestAnimationFrame викликає твою функцію щокадру (~60/с): ти оновлюєш позиції/повороти, потім renderer.render(scene, camera) малює кадр. У коді — функція tick(dt).
Camera (камера)
PerspectiveCamera визначає, яку частину сцени видно (frustum: fov, aspect, near/far). У гонці дивиться збоку, біжуни рухаються зліва направо.
Bloom
Постобробка (UnrealBloomPass): яскраві пікселі «розливаються» свіченням. Саме звідси неоновий вигляд біжунів, а не зі світла.
Координати
Y — вгору, тому position.y = 1.25 підіймає торс. X — вздовж доріжки (дистанція = бали). Z — розводить гравців по «лейнах».

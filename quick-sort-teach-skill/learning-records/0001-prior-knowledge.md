# Прийшов із знанням рекурсії та merge sort; quicksort — біла пляма

Користувач підтвердив (стартове опитування): впевнено пише TypeScript, знає інші сортування (зокрема merge sort) і рекурсію/divide-and-conquer, але quicksort конкретно не реалізовував. Мета — фундамент CS, не співбесіда.

**Implications:** Не витрачати уроки на основи рекурсії чи Big-O означень. Будувати quicksort через контраст із merge sort (відоме → нове). Зона проксимального розвитку = крок партиціювання та аналіз гіршого випадку (чому O(n²) і як pivot це спричиняє).

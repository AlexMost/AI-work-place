# Generics: вміє використовувати, але не писав власні

Користувач (стартове опитування по Mission 2) підтвердив: впевнено використовує готові generics (`Array<T>`, `Promise<T>`), але **сам generic-функцій майже не писав** і не впевнений у `extends`-constraints та inference. Мета — глибоке фундаментальне розуміння, не «рецепти».

**Implications:** Зона розвитку = перехід від *споживача* до *автора* generic. Перший урок має закріпити ментальну модель «`<T>` — параметр для типів, який заповнює викликач (через inference)» і контраст із `any` (втрата інформації). Не починати з mapped/conditional types — це поза скоупом поки що. Constraints (`extends`) — наступний крок після того, як написання базового generic стане впевненим.

Quicksort — шпаргалка

Divide-and-conquer сортування. Серце — крок партиціювання. Tony Hoare, 1959.

Велика картина

  • Розділяй і володарюй. Обери pivot, постав усі менші ліворуч, більші праворуч, потім рекурсивно сортуй кожну половину.
  • Робота — ДО рекурсії. На відміну від merge sort (вся робота в злитті після), quicksort усе важке робить у partition перед рекурсивними викликами. Злиття не потрібне.
  • In-place. Сортує всередині того ж масиву через обміни (swap). Додаткова пам'ять — лише стек рекурсії.

Lomuto partition (TypeScript)

function quicksort(arr: number[], lo = 0, hi = arr.length - 1): number[] {
  if (lo < hi) {
    const p = partition(arr, lo, hi);   // pivot стає на фінальне місце
    quicksort(arr, lo, p - 1);       // ліворуч від pivot
    quicksort(arr, p + 1, hi);       // праворуч від pivot
  }
  return arr;
}

function partition(arr: number[], lo: number, hi: number): number {
  const pivot = arr[hi];          // беремо останній за pivot
  let i = lo;                     // межа зони "менших"
  for (let j = lo; j < hi; j++) {
    if (arr[j] < pivot) {
      [arr[i], arr[j]] = [arr[j], arr[i]]; // swap у зону менших
      i++;
    }
  }
  [arr[i], arr[hi]] = [arr[hi], arr[i]];   // pivot на своє місце
  return i;                       // індекс pivot
}

Інваріант партиціювання (Lomuto)

На кожному кроці циклу масив поділений на чотири зони:

[lo … i−1]

< pivot — уже відсортована зона менших

[i … j−1]

≥ pivot — зона більших-або-рівних

[j … hi−1]

ще не розглянуті

[hi]

pivot — чекає в кінці

Пастки

  • Гірший випадок на відсортованому масиві, якщо pivot = перший/останній. Лік: рандомний pivot або «median-of-three».
  • Нестабільність — не зберігає порядок рівних. Якщо потрібна стабільність → merge sort.
  • Дублікати вбивають продуктивність → 3-way partition (Dutch National Flag).

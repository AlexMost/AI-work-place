# Початковий рівень і мета встановлені

Олекс заявив рівень CSS-анімацій «майже з нуля»: базовий CSS знає, але
`transition` / `@keyframes` / `transform` — туманно. Мета — **сам** писати такі
анімації (не делегувати агенту), включно з дебагом «не анімується».

Тому ZPD: починаємо з найдрібнішого атома — `transition: transform` як механізм
слайду (урок 0001), і лише потім нашаровуємо easing, `@keyframes` і FLIP.

Сильна перевага: він щойно наживо бачив, як ми будували й дебажили цю саму
анімацію в грі 2048 (баг телепортації + фікс через inline transform/reflow), тож
кожен урок прив'язуємо до реального коду гри — це його найкращий гачок.

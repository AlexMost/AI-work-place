# Mission: CSS-анімації плиток (як у 2048)

## Why
Олекс хоче **сам** писати плавні CSS-анімації переходів — такі, як рух і злиття
плиток у грі 2048, яку ми щойно зробили разом. Мета — не просити агента, а
розуміти й писати руками, включно з дебагом, коли «не анімується».

## Success looks like
- Може з нуля зробити, щоб елемент плавно їхав по координатах при зміні стану (slide)
- Може зробити «поп» при появі/злитті через `@keyframes`
- Розуміє, ЧОМУ новий елемент іноді телепортується замість слайду, і вміє це
  полагодити (forced reflow / FLIP)
- Може підібрати easing і тривалість під потрібне «відчуття» руху

## Constraints
- Рівень: майже з нуля (базовий CSS є; `transition` / `@keyframes` / `transform` — туманно)
- Мова навчання: українська
- Вчиться найкраще на практиці — хоче писати руками, а не лише читати
- Уроки короткі, по одному відчутному виграшу

## Out of scope (поки)
- JS-анімаційні бібліотеки (GSAP, Framer Motion) — спершу нативний CSS
- SVG / canvas / WebGL анімації
- Складна 3D-трансформація
